# Unbothered

(Formerly Unbowed and Stoic Reps. Data is still stored under the `stoicreps.v1` key, so logs carry over.)

A small offline training log (pull-ups, push-ups, squats, lunges) with double-progression suggestions, a daily
workout picked from your last four weeks (what's due, what's recovered),
runs, pool and open-water swims and soccer read from Garmin .fit files (or added by hand),
records, charts and verified Stoic quotes. Installable on iPhone: open the site in Safari → Share → Add to Home Screen.

All data stays on the device (localStorage). Use More → Backup to export/import JSON.

Quotes are checked word for word against public-domain translations: Marcus Aurelius and Epictetus (tr. George Long),
Seneca (tr. Richard M. Gummere). About 40% of quotes are in the Stoic spirit instead: the Dark Knight trilogy, Rocky, Roosevelt,
Invictus, Kipling, Shakespeare, Frankl and others (see quotes.js for sources).

Home-screen widget: iPhone doesn't let web apps make widgets, so `widget/unbothered-widget.js` is a script for the free
Scriptable app. Unbothered hands it your streak and today's workout when you tap ⇪ Widget (More → Home-screen widget has the setup).
